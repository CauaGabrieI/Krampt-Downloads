# Krampt Desktop

Instaladores públicos do Krampt para Windows e Linux.

Baixe a versão mais recente na [release atual](https://github.com/CauaGabrieI/Krampt-Downloads/releases/latest).

Este repositório distribui somente os instaladores e seus checksums SHA256. Não contém o código-fonte do aplicativo, dados dos usuários ou credenciais.

As atualizações são verificadas no servidor do Krampt. Nenhum login ou token do GitHub é necessário para baixar os instaladores.

## Verificação

Compare o SHA-256 do arquivo baixado com [`checksums.txt`](checksums.txt).
